# SignSetu

SignSetu is an offline-first, AI-powered healthcare communication assistant designed to facilitate accessible communication in healthcare settings.

## Overview
- **Offline-First**: Operates locally to ensure availability without continuous internet access.
- **Healthcare Communication**: Assists in bridging communication between healthcare providers and patients.
- **Local AI Processing**: Designed to utilize locally hosted AI models.

## Project Structure
- `backend/`: Backend services and local processing logic.
- `frontend/`: User interface components.
- `docs/`: Project documentation and guides.
- `assets/`: Static assets and media files.
